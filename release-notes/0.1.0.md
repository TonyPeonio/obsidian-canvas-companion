First release.

- One note per Canvas course with Upcoming / Past due / Done assignments as Tasks-style task lines, the latest announcements as markdown, and the current grade; the plugin edits only its own marked blocks, your notes in the file stay.
- A *This week* note: overdue work first, then every assignment due in the next seven days across courses, one section per day.
- Optional `.ics` calendar feed of upcoming deadlines.
- Sync on startup and on a timer; unchanged notes are not rewritten. Hidden courses and course name aliases.
- Clear errors for a bad token or an unreachable Canvas; a course whose assignments are hidden is kept with a warning instead of failing the sync.
