Tested against a mock Canvas server; nine fixes, no new setup.

**Fixed**
- One course that forbids announcements (403) no longer blanks announcements for every course: the plugin falls back to one request per course and marks only the refused one.
- An invalid or expired token now says so and tells you where to make a new one (Account → Settings → Approved Integrations → New Access Token).
- Link-header pagination no longer breaks on cursor URLs that contain commas.
- Late submissions are marked `⚠️ late` on their task line.
- The .ics feed is strictly RFC 5545: no `DTEND` equal to `DTSTART`, a DESCRIPTION on every event, CRLF endings, 75-octet folding that never splits a multi-byte character, escaped commas/semicolons/backslashes, stable UIDs.
- Notes with CRLF line endings keep them; a sync that changes nothing writes nothing.
- *Open this week* opens the note, or syncs first when it does not exist yet, instead of creating an empty file.
- When both assignments and announcements fail for a course, the warning names both.

**Measured**
- 43 tests (was 21), including an in-process mock Canvas HTTP server that drives the real client and sync through pagination, the `while(1);` prefix, 401/403 bodies, graded/unsubmitted/late submissions and the enrollment grade shapes.

**Docs**
- README: step-by-step token creation, the five read-only endpoints the plugin calls, the sync schedule, and the Companion suite.
